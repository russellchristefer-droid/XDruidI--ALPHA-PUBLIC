## Triage categories

Every item is categorized as exactly one of:

- **bug** — reproducible defect in current alpha systems.
- **enhancement** — request for new behavior or polish within existing pillars.
- **question** — clarification needed; answered in FAQ or public response.
- **duplicate** — already tracked; link to original with source attribution.

Severity: Critical (data loss, unplayable), High (core loop blocked), Medium (notable friction), Low (cosmetic or edge).

Affected system: named from SYSTEM_MAPS.md (yard, farming, animals, inventory, magic, save, portals, etc.).

## Rules

- Never promise features, dates, or inclusion. Log the request with source attribution and feed high-value items into the Chief of Staff backlog as explicit work orders.
- Draft public responses for common questions; maintain the living FAQ.
- Attribute every item: channel, date observed, reporter if known, quote or summary.
- Alpha honesty: the game is work in progress; saves are local and may change; PC desktop browser only.
