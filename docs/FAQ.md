# FAQ — XDruid I / Assay Homestead (Alpha)

**Dated:** 2026-11-26  
**Work order:** COMM-001  
**Status:** Living. Updated as the game evolves.  
**Hyper-realism check:** Honest, clear, no promises. A player reading this knows what the current alpha is and is not.

## What is this?

XDruid I (Assay Homestead) is a SNES-style persistent homestead life-sim you play in a desktop browser. One druid tends a floating yard, farms, keeps animals that remember you, trains magic in the courtyard, and travels through portals. The live build is at https://xdruidi.grok.me. It is not Unity, not Godot, and not a finished product.

## Do I need an account?

No. Ordinary play stores the homestead in your browser (localStorage key `assay-homestead-v2`). There is no account required for the yard. Sign-in, if a host offers it, is separate from the save.

## Where is my save?

Local to the browser profile on that device. Anyone who can use that profile can open the save. Use a device you trust. The format is not stable; alpha changes can affect old saves. Quarantine and backups exist; see the save notes in the knowledge base.

## Can I play on my phone or tablet?

The game asks you to continue on a personal computer. It is built for a desktop browser. A phone or tablet is not the intended surface.

## Will my save work in future builds?

Not guaranteed. This is alpha. The yard, gates, spells, and days can change. There is no warranty that a save from this build will load unchanged later. Back up your browser profile if the homestead matters to you.

## How do I report a bug or suggest something?

Open a GitHub issue on https://github.com/russellchristefer-droid/XDruidI--ALPHA-PUBLIC (or the current public repo). Include steps, what you expected, what happened, and which system (yard, animals, save, etc.). Security issues go privately. Do not put private facts in the yard or pack notes.

## Will you add [feature]?

Requests are logged with source attribution and reviewed against the contract and design pillars. We do not promise features or dates. The living roadmap distinguishes committed work from aspirational ideas. Priority is decided by the roster under the contract, not by any single request.

## What is in the current alpha?

Persistent homestead yard with beds, animals (cow, rooster, goat, sow, cat) that retain persistent memory, fishing pond, magic courtyard, portals to several lands, 28-slot pack with weight, tools that spend Floor, day/night clock, local save with checksum and quarantine, opt-in local telemetry, and a versioned modding path. See the public changelog source and docs/ROADMAP.md for committed versus aspirational.
