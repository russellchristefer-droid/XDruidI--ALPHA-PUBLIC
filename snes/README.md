# XDruid I — SNES sidecar

`xdruid.sfc` is a 32 KB LoROM cartridge. It is the homestead you can carry into an SNES emulator. It is not the browser game squeezed into the console. The console shows the yard, the seal, the west gate, and the east gate.

Open `xdruid.sfc` in Snes9x, bsnes, Mesen-S, or RetroArch with the snes9x core. Load the file the way you would load any other game. Nothing else has to be installed.

The D-pad walks. The west side of the path is Naraka, and the grass goes red. The east side is Svarga, and the grass goes gold. Walk back to the middle and the farm is green again.

Rebuild it with `python3 snes/build_rom.py`.
