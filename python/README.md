# XDruid I — Python sidecar

**Stage:** Alpha companion. Not a port of the browser client.

`xdruid.py` opens the homestead in a desktop window. Window title: `XDruid I — Alpha`. It is not the browser game and it is not the SNES cartridge. It does not include the DNA ladder halls, Floor 332, the mansion, the offline visit gate, the sow, or the volume buses.

Python 3 is enough. Tkinter comes with Python on Windows and macOS.

[Download xdruid.py](https://github.com/russellchristefer-droid/XDruidI--ALPHA-PUBLIC/raw/main/python/xdruid.py)

```bash
python3 xdruid.py
```

WASD or the arrow keys walk. Scroll the mouse wheel down to zoom out, and up to come back in. The goat stays inside the 7 by 3 pen on the upper farm. Xiang Su stands on the sidewalk. The west side of the yard goes red for Naraka. The east side goes gold for Svarga.

The SNES cartridge is [xdruid.sfc](https://github.com/russellchristefer-droid/XDruidI--ALPHA-PUBLIC/raw/main/snes/xdruid.sfc).
